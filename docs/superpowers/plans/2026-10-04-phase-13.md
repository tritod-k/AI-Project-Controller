# Phase 13 Independent LLM Reviewer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Add an independent stateless semantic reviewer behind the existing Reviewer contract.

**Architecture:** Provider-neutral validated request/normalization/audit/reviewer code
uses a narrow async transport. An optional pinned OpenAI Responses transport has no
tools or worker session. Existing Controller, PhaseGate and public schemas are unchanged.

**Tech Stack:** Python 3.11+, Pydantic 2, asyncio, atomic JSON storage, optional openai==3.24.0, pytest/Ruff.

**Spec:** `docs/superpowers/specs/2026-10-04-phase-13-design.md`, grounded in the explicit human implementation brief.

## Global Constraints

- Only Phase 13; branch codex/phase-13-attempt-01 from aipc-phase-12-pass.
- Canonical ReviewResult and all six public schemas unchanged.
- No Codex worker/session/context reuse, tools, web, implicit fallback or consensus.
- Evidence is untrusted user data; structural and objective checks remain authoritative.
- Base package works without OpenAI/Codex extras; no secrets or hidden reasoning retained.
- Manual external review remains authoritative; finish AWAITING_REVIEW/PENDING without a PASS tag.
- Preserve evidence/receipts; one coherent final attempt commit rather than per-task production promotion.

## Review Focus

- Context/evidence changes while the provider is running must reject stale results.
- Budget limits and redaction must not allow a partial semantic citation to become PASS.
- Interrupted paid-call intents and lease ownership must not cause a blind second dispatch.
- Objective evidence must prevail even when a valid structured model proposal is optimistic.
- Sync use inside the existing async Controller must not reuse worker context or a nested event loop.
