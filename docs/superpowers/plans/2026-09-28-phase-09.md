deterministic objective reviewer, separate gate and existing-component integrations.
**Tech Stack:** Python 3.11+, existing Pydantic 2, pytest; no new dependencies.
**Spec:** docs/superpowers/specs/2026-09-28-phase-09-design.md

## Global Constraints

Only Phase 09; no provider calls, commands during review, runtime Git mutation,
public schema changes, master merge or PASS tag. Preserve previous safety boundaries.
One coherent attempt commit after full validation, optional documentation handoff.

## Review Focus

- Mutable canonical collections must be revalidated, including review lists.
- Forged or stale artifacts must not authorize a different attempt/commit.
- Optional failures must not accidentally become required or disappear.
- ERROR/BLOCKED must not produce worker repair or stable authorization.
- Running work and contradictory reviews must fail closed even with a PASS label.
