# Phase 07 Implementation Plan

> For agentic workers: use superpowers:executing-plans inline. The user explicitly
> authorizes end-to-end execution without approval pauses and requests one attempt commit.

Goal: safe immutable Git checkpoints, persisted inspection and isolated restore/worktrees.
Architecture: VersionManager -> typed records / atomic storage -> fixed GitBackend commands.
Tech stack: Python >=3.11, existing Pydantic 2, stdlib, pytest and Ruff; no dependencies.
Spec: docs/superpowers/specs/2026-09-27-phase-07-design.md.

## Global constraints

Phase 07 only, base 59a5121458cd1f1dcc4f72425fd925a53531756a;
branch codex/phase-07-attempt-01. No real checkpoint refs, PASS tags or stable promotion.
Source mutation tests use disposable repositories; source/templates/canonical schemas unchanged.

## Review focus

- Dirty, ignored, staged and untracked files survive refusals and worktree removal.
- Approval is explicitly bound to immutable attempt identity and exact commit.
- Parent ancestry, metadata and Git refs agree after restart; partial writes fail closed.
- Worktree paths cannot escape through syntax, links/junctions or substituted repositories.
- Git hooks, filters and submodules cannot cause hidden execution during worktree checkout.
