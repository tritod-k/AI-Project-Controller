## Contract Decisions and Compatibility

This is the first canonical release; no earlier Python canonical contract requires migration.
The current user instruction and blueprint section 33 require schema_version on TaskRequest
and ApprovalRequest despite its omission in their section 4 examples.

Core records reject extra fields. Optional JSON-only `metadata` defaults to a fresh object
on each root model so future extensions stay outside core fields. Other blueprint fields
are required, including nullable unknown evidence fields, to avoid fabricating facts.
AgentResult `tests` may be null when unavailable; known counts must sum to total.
Timestamps accept timezone-aware datetime objects or ISO strings, never numeric epochs.
Temporal ordering is a structural check, not phase policy. Agent completion does not
imply PASS, and review verdict does not mutate or authorize controller state.

Unspecified task/action types stay open nonblank strings. File change types are
added/modified/deleted/renamed; criterion statuses are PASS/FAIL/UNVERIFIED.
Artifact descriptors remain JSON values because the blueprint does not define their shape.
AgentCapabilities belongs to Phase 03 and is deferred.
