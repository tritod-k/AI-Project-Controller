# Phase 06 Evidence Collector Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline. Test-first tasks
> below implement the explicitly authorized user brief without approval pauses.

**Goal:** Persist observable and declared evidence separately for later review.
**Architecture:** Typed manifests join canonical snapshots, fixed read-only Git
observations, parsed pytest logs and bounded safe file copies. Manifest publication
is atomic and last; an attempt directory is never overwritten.
**Tech Stack:** Python >=3.11, existing Pydantic 2, stdlib, pytest/Ruff.
**Spec:** docs/superpowers/specs/2026-09-27-phase-06-design.md
